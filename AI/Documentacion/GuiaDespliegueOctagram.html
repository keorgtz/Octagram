🚀 Guía de Despliegue: Octagram Delivery

Guía paso a paso para desplegar la PWA y la API de Octagram en Ubuntu Server usando Docker, Nginx Proxy Manager y Cloudflare Tunnel.

Pre-requisito Importante: Esta guía asume que ya has seguido la GuiaUbuntuServer.md y tienes instalados y configurados: Docker, Docker Compose, la red global 'proxy', Nginx Proxy Manager (NPM) y Cloudflare Tunnel.

1 Arquitectura del Proyecto

La aplicación consta de tres contenedores principales definidos en el archivo docker-compose.yml:

  • octagram-db: Contenedor de SQL Server 2022.
  • octagram-api: Backend ASP.NET Core 10 (Puerto interno 8080).
  • octagram-client: PWA en Blazor WebAssembly servida por Nginx Alpine (Puerto interno 80).

Todos estos contenedores están conectados a la red externa proxy para interactuar de forma segura con Nginx Proxy Manager sin exponer puertos al exterior.

2 Preparar el Código en el Servidor

Conéctate a tu servidor Ubuntu por SSH y clona el repositorio de la aplicación dentro de tu carpeta de aplicaciones Docker.

cd /root/docker/apps
git clone <URL_DE_TU_REPOSITORIO> octagram
cd octagram

3 Levantar los Contenedores

Construye y levanta los contenedores en segundo plano. Docker Compose se encargará de compilar la API y el Client usando sus respectivos Dockerfiles.

docker compose up -d --build

Verifica que los contenedores estén corriendo correctamente:

docker ps

Deberías ver octagram-db, octagram-api y octagram-client en ejecución.

4 Configuración de Nginx Proxy Manager (NPM)

Accede a la interfaz de Nginx Proxy Manager (usualmente http://<IP_DEL_SERVIDOR>:81) y crea dos Proxy Hosts.

🌐 1. Proxy para la API (Backend)

  • Domain Names: octagram-api.endevour.mx
  • Scheme: http
  • Forward Hostname / IP: octagram-api (nombre del contenedor)
  • Forward Port: 8080
  • Block Common Exploits: Activado
  • SSL: Solicitar o asignar certificado SSL, activar Force SSL.

📱 2. Proxy para el Client (PWA)

  • Domain Names: octagram-app.endevour.mx
  • Scheme: http
  • Forward Hostname / IP: octagram-client (nombre del contenedor)
  • Forward Port: 80
  • Block Common Exploits: Activado
  • SSL: Solicitar o asignar certificado SSL, activar Force SSL.

5 Configuración de Cloudflare

Asegúrate de que en el panel de DNS de Cloudflare (o en tu config.yml del tunnel) existan los registros apuntando a tu túnel:

# En config.yml de Cloudflared (Si usas ingress local)
- hostname: octagram-api.endevour.mx
  service: http://npm:80

- hostname: octagram-app.endevour.mx
  service: http://npm:80

Nota: Si configuraste el túnel desde el Dashboard de Cloudflare Zero Trust, simplemente agrega los subdominios públicos apuntando al servicio HTTP de tu NPM (ej. http://localhost:80 o la IP del Nginx Proxy Manager).

6 Migraciones y Base de Datos

El backend se conecta al contenedor octagram-db. Asegúrate de que Entity Framework aplique las migraciones automáticamente al arrancar la API, o ejecútalas manualmente si así lo requiere tu configuración:

docker exec -it octagram-api dotnet ef database update

(Asegúrate de que el contenedor de la API tenga las herramientas de EF si necesitas hacerlo manual, de lo contrario, aplica la migración en el Program.cs en el arranque).

✅ ¡Despliegue Completado!

La aplicación debería estar disponible en:

  • App PWA: https://octagram-app.endevour.mx
  • API Swagger/Endpoints: https://octagram-api.endevour.mx

🛠️ Comandos Útiles de Diagnóstico

Para ver los logs de los servicios si algo sale mal:

# Logs de la API
docker logs octagram-api

# Logs del Client
docker logs octagram-client

# Logs de la Base de Datos
docker logs octagram-db
