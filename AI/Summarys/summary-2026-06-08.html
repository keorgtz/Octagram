Fix: Secciones sin productos en Stocks de Reparto

Fix
Secciones siempre se cargan desde la API
Antes, CargarDatosNegocioAsync() solo cargaba secciones desde la API cuando _secciones.Count == 0. Si el snapshot local tenía secciones (aunque fuera con stocks vacíos o desactualizados), no se actualizaban desde la API. Ahora siempre se obtienen secciones y grupos actualizados desde la API cuando hay conexión, garantizando que los productos asignados a secciones se muestren correctamente.
JornadaPage.razor · CargarDatosNegocioAsync
Fix
Eliminada dependencia de SyncNegocioDataAsync para carga de secciones
El método SyncNegocioDataAsync tiene un flag _syncingNegocio que bloquea llamadas concurrentes. Si la sincronización periódica estaba en progreso, CargarDatosNegocioAsync recibía null y no actualizaba los datos. Ahora se llama directamente a Api.GetSeccionesAsync() y Api.GetGruposProductoAsync(), evitando el bloqueo.
JornadaPage.razor · CargarDatosNegocioAsync

Pendientes y riesgos

  • warning
    GestionSecciones y AsignarJornada aún no tienen gate en vistas. Los permisos existen en el enum y en la UI de configuración, pero las vistas de Secciones y JornadasActivasPage no verifican estos permisos para Supervisor. Se recomienda agregar los gates en una próxima sesión.
  • info
    Permisos existentes de Supervisores. Los Supervisores que ya tenían permisos configurados con el enum anterior (5 permisos, Todo=31) conservan sus flags en la BD. El nuevo Todo=255 incluye los 3 permisos nuevos. Los Supervisores existentes necesitarán que se les asignen los nuevos permisos manualmente desde la UI de administración.
  • info
    Admin en jornada ajena. Cuando Admin accede a /gerente/jornada/{id}, las secciones se cargan desde la API (no hay snapshot local). La primera carga puede ser ligeramente más lenta que para el Repartidor.
